# 🚗 Tama Rent Car And Travel — Landing Page

Landing page modern dan responsif untuk **Tama Rent Car And Travel** (Layanan rental mobil premium & travel di Medan Marelan).

## ✨ Fitur Utama
- **Responsive Navbar & Hero Section**: Efek glassmorphism dan partikel interaktif.
- **Katalog Armada & Filter Kategori**: Filter instan untuk *Semua*, *Mobil Keluarga*, dan *VIP*.
- **Integrasi Pemesanan WhatsApp Dinamis**: Otomatis menyusun template pesan WhatsApp berdasarkan unit dan harga mobil yang dipilih.
- **Animasi Scroll Halus**: Dibangun dengan Vanilla JavaScript (`IntersectionObserver`) dan CSS3 modern.

## 🚀 Cara Menjalankan
Buka langsung file `index.html` di browser atau akses melalui GitHub Pages:
- **Live Demo**: [https://degray234.github.io/LandingPage/](https://degray234.github.io/LandingPage/)
